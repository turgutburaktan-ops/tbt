# Video review implementation — 12 September 2026

Based on the two user-provided recordings and the approved task list.

## Implemented locally

- Personal profile default and server-managed journey titles (prior commits).
- Person search matches name/username rather than city; Turkish normalization,
  debounce, query-scoped result builders, search filters and cached legacy lookup.
- Bookmark/repost lists retain owner filtering, retry and an index-error fallback.
- Direct chat creation tolerates a denied read of a nonexistent thread by using
  the existing callable; server membership/privacy checks remain authoritative.
  Read receipts no longer block the screen; initial loading has a timeout/retry.
- Published place queries use a simpler server query; the existing decoder still
  requires published status plus verified coordinates and images. Loading has
  an explicit failure/retry state and never substitutes unpublished bundled data.
- Short suggested routes cluster stops, budget visit time and omit water-transfer
  destinations. Smart routes trim stops if the returned travel duration is too long.
  Route distance displays remain estimates, not a guarantee of live road access.
- Emergency shelter names excluded from hotel results and cached update displays.
- Black/neutral shared surfaces, violet primary actions, compact home/story chrome,
  header sharing button and horizontally scrolling place categories.
- Three primary planning actions; advanced tools remain accessible in an expansion.
  Quick planning asks city/time/mood first and collapses other preferences.
- Published place photography in planning; only one alternative is initially open.
- Profile content above management tools, which remain available in one sheet.
  Default identity remains personal, not traveler. Profile tab names are visible.
- Nearby events use one list and one empty state; data failures are distinct.
- Inbox emphasizes new messages; groups, privacy and notifications remain in menu.
- Settings group notification and history details; journey cards retain thresholds
  while collapsing scoring rules and highlighting earned badges.
